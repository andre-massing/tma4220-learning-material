Mathematical Sciences, NTNU.

:::{note}
This is a minimal skeleton. Content is under construction.
:::

## Running the code

Every notebook in this book can be executed directly in your browser — no local
Python installation required. Look for the **power button** (⏻) at the top of a
page with code on it: pressing it starts a JupyterLite kernel running entirely
inside the browser via WebAssembly, after which the code cells become editable
and runnable.

The first launch takes a few seconds while the runtime downloads. After that,
execution is local to your machine and nothing is sent to a server.
